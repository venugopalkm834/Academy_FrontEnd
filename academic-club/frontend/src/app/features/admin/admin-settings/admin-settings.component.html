Payment Settings

1. When is payment required?

Membership prices and plans (one-year / lifetime, per education group) are managed under Membership Plans. During the free days members use everything without paying. After that the mode above applies. Each member's free days are fixed when they register.

2. Partner fees (institutions that list themselves)

Plan A = normal listing of their details and offerings. Plan B = featured sponsor on the main page. Set a fee to 0 to make a plan free.

3. Landing page numbers and registration

Counters on the home page show real counts. To show a different number (for example a target), enter it here; 0 = use the real count. Numbers are rounded, e.g. 1,234 shows as 1,200+.
